# GenericDice
Description:
This program allows users to request a die based on number of sides. The sizes of the die include: d4, d6, d8, d10, d12, d20. A random number is generated after each roll and the user decides if he wants to keep playing. 

Development Environment:
The development environment included Python 3.x, Python IDLE, Git, and GitHub

Run:
To run the function, Open GenericDice.py in IDLE. Die size will be requested and the result of the roll will be generated.
